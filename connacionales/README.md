# Bantrab · Connacionales

Peça HTML5 criada a partir do PSD `Slide 5.psd` nos formatos 300×250, 400×300 e 600×400. Os elementos tipográficos, logos e fotografia foram extraídos do próprio PSD. O catavento gira continuamente e o CTA “Conoce más aquí” pisca.

Os três ZIPs independentes ficam em `packages/`. A prévia é `preview.html`.

Destino de clique provisório: https://www.bantrab.com/ — substituir pela URL aprovada para esta campanha.
