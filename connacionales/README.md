# Bantrab · Connacionales

Peças HTML5 Floating Object e 3D Cube criadas a partir do PSD `Slide 5.psd` nos formatos 300×250, 400×300 e 600×400. Os elementos tipográficos, logos e fotografia foram extraídos do próprio PSD. O catavento gira continuamente e o CTA “Conoce más aquí” pisca. No 3D Cube, a primeira tela vira como uma página para revelar a tela com logo, CTA e assinatura.

Os seis ZIPs independentes ficam em `packages/`. A prévia é `preview.html`.

Destino de clique provisório: https://www.bantrab.com/ — substituir pela URL aprovada para esta campanha.
