# Bantrab — Tuyo desde hace 60 años

Seis peças HTML5: Floating Object e 3D Cube em 300×250, 400×300 e 600×400 px.

- Preview: `/p/bantrab-60-anos`
- Cada pasta de formato e tamanho contém `index.html`, CSS, JavaScript e assets locais.
- Os seis ZIPs de entrega estão em `packages/` e podem ser baixados no preview.
- Sequência: artes 03 → 04 → 05 do material original; o Cube adiciona um encerramento de marca.
- Clique: `window.clickTag` ou `window.clickTAG`; destino padrão `http://bantrab.com/`.
- O único texto novo é o CTA “Conoce más”.

Para regenerar os arquivos após editar `src/`, execute `python3 60-anos/src/build.py` na raiz do repositório.
