# Rich media Bantrab

Este repositório publica a peça e o preview pela Vercel.

- Peça: https://rich-media-alpha.vercel.app/
- Preview para o cliente: https://rich-media-alpha.vercel.app/p/bantrab-tarjeta

Arquivos da peça atual:

- `index.html`: HTML e animações da peça.
- `mulher-compras-central-america.jpg`: fotografia usada na peça.
- `preview.html`: interface de apresentação.
- `vercel.json`: rota amigável do preview.

As próximas alterações devem ser feitas nesta cópia local do repositório e enviadas à branch `main` para publicação pela Vercel.
