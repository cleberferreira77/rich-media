# Bantrab · YoLo

Peças independentes a partir de `4.psd` (Transfiero) e `SLIDE 10YOLO.psd` (Cobro). Cada uma tem Floating Object e 3D Cube nos formatos 300×250, 400×300 e 600×400 px.

Destino de clique configurado: https://yolo.com.gt/descargarweb/

No Transfiero, o logo aparece primeiro, o apoio é digitado e a caixa de download entra depois. No 3D Cube, cada letra do logo gira 360° em sequência, com apoio fixo e caixa pulsante. No Cobro Floating, as linhas entram de cima para baixo e a caixa de download pulsa. No Cobro Cube, a frente e a face de download alternam em giros de 90° para a esquerda.
